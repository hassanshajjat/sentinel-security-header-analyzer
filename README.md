# Sentinel — Security Header Analyzer

A lightweight Python tool for analyzing HTTP security headers and identifying common web security hardening gaps.

> Learn. Analyze. Understand. Secure.

---

## 01 / OVERVIEW

**Sentinel** is a lightweight security-focused Python tool designed to inspect HTTP response headers and identify missing or weak security configurations.

The project is built as a learning-focused security utility for exploring how web applications communicate and how security controls can be implemented at the HTTP layer.

---

## 02 / FEATURES

- HTTP security header analysis
- Detection of missing security headers
- Weighted security score calculation
- Simple security assessment
- Redirect-aware analysis
- Configurable request timeout
- Lightweight Python implementation
- Beginner-friendly security research project
